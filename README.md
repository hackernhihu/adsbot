# Ads Bot for Telegram

## Features
- User must join 2 channels
- Add Telegram accounts (1 for free, 5 for premium)
- Create ads and auto-post every 5 minutes
- Premium plans with UPI payment
- 7-day free trial

## Commands
- /start - Start bot
- /utr UTR PLAN - Submit payment

## Admin Commands
- /approve USER_ID - Approve premium
- /reject USER_ID - Reject premium
- /ban USER_ID - Ban user
- /unban USER_ID - Unban user
- /broadcast MSG - Broadcast message

## Setup
1. Replace CHANNEL_1 and CHANNEL_2 with your channels
2. Add bot as admin in both channels
3. Deploy on Railway
